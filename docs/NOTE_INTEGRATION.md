# AST Pocket Ver.2 自動ノート統合（第1段階）

## 概要
Weeklyの学習ポイントと復習Q&Aを既存の分野別ノートへ自動関連付けします。ノート未作成のテーマにも学習用の自動生成画面を設けます。

**本段階はルールベースの自動統合であり、生成AIによる臨床文章の創作・正誤判定・意味的な要約は行いません。**

## 動作
1. Pages公開時に `node scripts/organize-weekly.mjs --write` を実行。
2. 続けて `node scripts/propose-integrations.mjs --write` を実行。
3. `content/integration-proposals.json` をサイト公開物に生成（リポジトリ本体には自動コミットしない）。
4. Homeの分野別一覧 → ノートを開く → **学習モード**で追記候補を見る。
5. 元Weeklyのページへ遡れる。医学的記述は「原典確認待ち」一覧へまとめる。

## データ管理と安全
- 生成された `facts` は同じ文章を安定したIDで重複統合し、元Weeklyへの参照ポインタを複数記録する。
- `topics` は、1つの知識IDに複数の菌・薬剤・感染症・AST項目からリンクできる。
- 元本文、既存Markdown、確認済みのKnowledgeは自動で変更しない。
- draft と review_required は医学的な正しさを意味しない。
- 薬剤の選択、投与量・期間、感染症診療の方針などに関わる記述は原典確認待ちとして扱う。
- 臨床モードの30秒要約には自動生成・未確認の知識を流し込まない。
- 「医学的な原典を確認した／承認済み」へ格上げする機能は本段階にはない。承認は別段階で証拠資料と操作履歴を紐付けて設計する。
- 分類精度は定義された単語・別名に依存し、意味的に似ているだけの表現や複雑な矛盾は自動検出しない。
- 公開リポジトリなので、患者を特定できる情報・院内限定情報をWeeklyへ入力しない。公開前の情報保護は必須。

## 対象データ
- `content/index.json` に登録されたWeeklyの「今週の重要ポイント」「今週の復習」から、新しい知識候補を抽出。
- 「今週の学習」「正式ノート候補」はテーマへのリンクに使用。
- 既存の登録ノートがある場合は、その項目別の追加候補を学習モードで表示。
- 既存の登録ノートがない場合は、タイトル・分類・学習メモ・出典から学習用ノート画面を自動構成。
- 新しいWeeklyが登録されるたび、次のPagesデプロイ時に再計算。

## 実行テスト
```bash
node scripts/organize-weekly.mjs --write
node scripts/propose-integrations.mjs --write
node scripts/test-integrations.mjs
node scripts/test-integration-ui.mjs
```

- 未分類学習の確認・分類の修正・見落としの監査。
