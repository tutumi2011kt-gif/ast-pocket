# AST Pocket V2 — 復習機能（ドラフトPR）

## 実装済み
- 平日5問・土日10問（日本時間判定）。問題は日ごとに決定的な順序で選ぶ。同日に同じ問題は再出題しない。
- 間隔反復（1、3、7、14、30日目安）、前回の回答に応じた「要復習」「未回答」優先選択。
- 選択式問題の練習上の自動判定、記述式のモデル回答提示と自己評価（回答テキストの入力・保存なし）。
- 「もう一度」「まだ不安」「理解できた」「すぐ答えられる」の4段階で学習履歴を保存。
- ブラウザのIndexedDBを用いた端末内保存。保存できない環境では、回答記録の操作を有効化しない。
- 手動JSONバックアップ出力と重複イベントIDを除外する取り込み。データがあれば初回案内を出し、利用者が「保存済み」と確認した7日後から再案内。
- Studyモードだけで下書き問題を表示。Clinicalモードからは学習モードへ切替を案内。

## 安全上の注意
- 初期問題12問は既存のAST Pocket内のMSSA菌血症、S. maltophilia、10月9日Weeklyから作成した原典未検証の練習問題です。**医学的に検証済みとはみなしません**。
- 問題には原本ファイルのパス・セクション名・draft状態を記録。一次情報源URL、確認者、確認日を伴う verified 問題だけが将来の正式な定着度判定の対象になります。
- 下書き問題でも自分で考える練習のため出題・履歴保存はできますが、正解率だけで正式な臨床知識の習熟を確定しません。
- 回答履歴はGitHub Pagesや外部APIへ自動送信しません。端末には患者情報、氏名、自由記述の症例記録を入れないでください。
- ブラウザの設定変更、サイトデータ消去、プライベートモード等でデータを失う可能性があります。バックアップファイルも個人で安全に保管してください。
- JSONの書き出し成功と、利用者が実際に安全に保存したことは別です。アプリは利用者による明示的な保存確認を必要とします。
- IndexedDB保存データは端末内であり、暗号化クラウド同期やGoogle Drive連携はまだありません。

## 画面
1. Homeで「学習モード」を選択。
2. 「今日の復習」または下部のReviewを開く。
3. 選択式では1つ選び「回答を確認する」、記述式では頭の中で回答し「模範回答を見る」。
4. 自己評価の4ボタンのいずれかを押すと回答履歴を保存して次へ。
5. Review画面の「JSONを書き出す」から保存。保存後「ファイルを保存済みとして記録」を押す。
6. 別のブラウザ・端末で復元するときは「JSONを読み込む」を利用。
