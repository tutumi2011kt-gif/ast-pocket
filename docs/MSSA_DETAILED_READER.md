# AST Pocket：詳細型学習ノート／MSSA菌血症パイロット（2026-10-11）

## 位置づけ

学習ノートは「臨床で30秒で要点にアクセスできる」と「教科書のように詳しく学ぶ」の両立型。
現在のMSSA菌血症ノートは **医学的原典の確認が完了していないdraft** であるため、学習モードにのみ医学的な原案本文・比較表・架空症例・フローを表示する。臨床モードでは臨床推奨を確定表示せず、未確認のチェック項目案と原典未確認の警告を表示する。

今回の変更は**ノートのUIと読書体験の実装**であり、ガイドラインの内容を新たに承認したものではない。

## 画面と操作

- HomeからMSSA菌血症ノートを開き、「学習モード」にする。
- **第1層：30秒で全体像**：既存draftの30秒要約を表示。
- **第2層：ASTで確認すること**：既存draftの情報収集項目を表示。
- **第3層：詳しい学習**：8章の詳細・比較表・概念フロー・架空症例・エビデンス。
- 「**要点**」は各章の冒頭2項目だけを表示。「**詳しく**」は既存Markdownの全項目・表・フロー・架空症例などを表示。設定は端末内に保存される。
- 「**前回の続きから再開**」は記録されたスクロール位置へ戻る（ノートが大きく改訂された場合、同一位置に一致しないことがある）。目次タップでは対応する章を開いて移動。
- 章の開閉状態、最後に開いた章、読書位置が同じブラウザ内のlocalStorageに保存される。患者情報や自由記述を保存する欄は設けない。
- ノートから他画面に戻る、Weeklyの元の出典を開く、既存の関連ノート検索などの操作は維持。

## 保存仕様

ブラウザのlocalStorageのキーは、MSSAノートIDに紐付けた専用キー。
格納する値は、次の**UI設定だけ**に限定する。

- 表示深度（simple / deep）
- 開いている章の固定ID
- 前回読んだ章の固定ID
- スクロール位置（数値）
- 保存時刻

患者名、自由記述、カルテ内容、抗菌薬オーダー、アカウント情報は保存しない。

プライベートブラウズ、端末のストレージ制限、データ消去時は保存されないことがある。別端末やブラウザとの同期はまだ行わない。ノートの表示自体はlocalStorageが利用できなくても継続できる。

## 医学的安全性

- MSSAノート自体のstatusはdraft、医学的原典の最終確認日は未入力のままとする。
- 構造更新日は医学的な承認日とは別の属性で保存する。
- 比較表とフローは学習の整理に限り、臨床判断・処方の確定に使わせない。
- Weeklyから自動整理された未確認メモは学習モードで候補表示のままにする。
- 具体的な抗菌薬選択、期間、腎機能別用量、禁忌等を正式な臨床情報として反映する際は、別途原典検証と承認が必要。

## テスト

- 8章・章IDの重複がないこと、ノート本文と連動すること。
- 要点／詳しくの表示差、外部出典リンク、比較表・フロー・架空症例の表示。
- 端末内での表示設定・開閉状態・読書位置の保存と、不正な章IDの除外。
- 臨床モードに未確認のWeekly・比較表・症例を表示しないこと。
- 既存の検索、Weekly表示、ノートリンクと戻るナビゲーションの回帰テスト。
- バックアップ機能（復習回答のJSON）は今回変更しない。ノートの「読書位置」は別ブラウザへ自動同期しない。
