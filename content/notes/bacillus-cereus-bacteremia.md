# まず覚える
- **ひとことで：B. cereusによる「真の菌血症」なら、静注VCM（バンコマイシン）は有力な経験的治療選択肢。**
- **ただし「Bacillus属が血培から出たら全例VCM」ではない。** 汚染（コンタミネーション）か真の感染か、菌種と臨床状況を先に評価する。
- Bacillus属は芽胞を形成するグラム陽性桿菌（GPR）。環境中に広く存在し、血液培養の汚染菌となることもある。
- *B. cereus*では多くのペニシリン系・セフェム系抗菌薬に耐性があり、CEZ・CTRX・ABPCに通常は治療効果を期待できない。
- 真のカテーテル関連血流感染症（CRBSI）なら、抗菌薬だけでなくカテーテル抜去の検討が重要。

# 汚染（コンタミ）と真の菌血症
- 複数の独立した血液培養セットが陽性なら真の菌血症を強く疑う。1本のみ陽性・感染徴候なしなら汚染の可能性がある。
- ただし好中球減少、血液悪性腫瘍、血管内カテーテル留置、発熱・ショックなどがあれば、1本陽性でも安易に汚染としない。
- 採血したセット数・陽性のセット数／ボトル数、末梢／カテーテル採血の別、採血時刻、再血液培養、他の感染源を確認する。
- 「血液培養が2セットとも陽性」だけで感染源がCVと確定するわけではない。必要なら末梢血とカテーテル血のペア培養・DTPなどを評価する。

# 代表的な感染症と感染源
- *B. cereus*の真の菌血症は、末梢静脈・中心静脈カテーテル関連感染が重要。
- 免疫不全患者では重症菌血症、眼内炎、中枢神経感染症などの合併症に注意。
- Bacillus属の全菌種に同じ抗菌薬方針を当てはめない。菌種同定・感受性結果を確認する。

# 自然耐性・耐性機序
- *B. cereus*はβラクタマーゼを産生し、ABPC・多くのセフェム系（CEZ・CTRXなど）に自然耐性を示す。
- MEPMなどのカルバペネム系、LVFXなどのキノロン系の有効性は菌株・感受性結果を踏まえて判断する。
- 2015年の国内29例研究ではVCM感性が29/29株だったが、全世界の全株で感性という保証ではない。

# 抗菌薬の選択
- *B. cereus*の真の菌血症が疑われる場合、**VCM静注**は根拠のある経験的治療候補。単なる血培陽性のみで自動開始はしない。
- CEZ・CTRXを投与中でも、*B. cereus*に対する適切な治療とは限らない。
- 同定菌種・感受性、腎機能、併用薬、血中濃度測定（TDM）と感染源を総合して投与設計を行う。
- MRSAのVCM AUC目標を*B. cereus*感染症に無条件で外挿しない。投与量・期間は患者状況と施設方針で検討する。

# カテーテル・感染源コントロール
- 真のBacillus属CRBSIと判断され、血液培養の汚染が除外されれば、短期・長期カテーテルとも原則として抜去を検討する。
- IDSA 2009の推奨では、複数の陽性培養があり、そのうち少なくとも1つは末梢採血であることを踏まえて汚染を除外する。
- 菌血症が持続する場合、カテーテル感染の持続、感染性心内膜炎、深部感染、敗血症性血栓性静脈炎などを再評価する。

# ASTで確認
- 菌種はBacillus spp.までか、*B. cereus*まで同定されたか
- 血液培養の採取セット数／陽性セット数、末梢採血かカテーテル採血か
- 発熱・血圧・炎症反応、好中球減少、血液悪性腫瘍、免疫抑制の有無
- CV・末梢静脈ライン・人工物の有無、抜去可能性、再血液培養
- CEZ・CTRXなど非活性の可能性がある薬剤を使用していないか
- VCMの適応、腎機能・TDM、感受性、治療反応、合併症

# 症例で学ぶ
- 例：CV留置患者が発熱し、独立した血液培養2セットから*B. cereus*陽性。CTRX投与中。
- 考え方：真の菌血症およびCRBSIを疑い、VCM静注の開始を検討。末梢・カテーテル採血の情報と再培養を確認し、カテーテル抜去を主治医に提案する。
- 注意：症例の設定だけでCRBSIの確定診断はできない。カテーテル抜去・感染巣評価・治療期間は個別に判断する。
