# まず覚える
- アミカシン（AMK）は30Sリボソームに作用するアミノグリコシド系の殺菌性抗菌薬。濃度依存性殺菌作用とPAE（抗菌薬作用後効果）がある。
- 5つの使い方を区別する：①一般的な注射治療、②PK/PDを利用した1日1回投与、③条件を満たす膀胱炎での単回投与、④特定の重症感染症での初期併用、⑤抗酸菌症での注射・リポソーム吸入。
- 1日1回投与と単回投与は異なる。1日1回は継続するスケジュールで、単回投与は原則1回で治療を終える。
- AMK単剤があらゆる重症感染症に適切なわけではない。感染部位、感受性、感染源コントロール、毒性を必ず検討する。

# 耐性・感受性と抗菌スペクトラム
- 主な標的は好気性グラム陰性桿菌。E. coli、Klebsiella、Pseudomonas aeruginosaなどは感性株であれば治療選択肢となる。
- ESBL産生菌、AmpC産生菌、CREでもAMKに感性の株が存在する。ただし耐性機序、MIC、感染巣により有効性は異なる。
- 緑膿菌への活性は菌株依存。必ず培養と感受性を確認する。
- 嫌気性菌には通常有効でない。EnterococcusやMRSAを対象とする標準的な単剤治療薬ではない。
- 感受性結果だけでなく感染巣への移行性を考え、特に非尿路感染での単剤治療は避ける。

# 治療の使い分け
- 単純性下部尿路感染症（膀胱炎）：ESBL産生腸内細菌目細菌などで感受性が確認され、患者条件が適切なら単回静注が選択肢となる（IDSA 2026）。腎盂腎炎・菌血症にそのまま外挿しない。
- 腎盂腎炎・複雑性尿路感染症：感性のESBL産生菌・CRE・難治性緑膿菌に対し、AMKの1日1回投与を代替選択肢として検討する場合がある。腎毒性は投与期間に依存するため再評価する。
- 重症グラム陰性菌感染症：耐性菌リスクが高く経験的治療のカバーが不確かな場合、初期のβラクタム薬との併用を検討することがある。感受性が判明すればAMK継続の必要性を再評価する。
- 非尿路の深部感染、肺炎、菌血症などでAMK単剤を標準治療としない。より適切な組織移行性と臨床根拠を持つ薬剤を優先する。
- 難治性肺MAC症：アミカシンリポソーム吸入懸濁液（ALIS、アリケイス）590mg吸入が、多剤併用療法に追加される場合がある。通常の注射用AMKと投与方法・適応を混同しない。
- ATS/ERS/ESCMID/IDSA 2020では、適切な多剤併用療法を少なくとも6か月行っても培養陰性化しない肺MAC症にALIS追加を推奨。注射用AMKは空洞性・高度肺MAC症やM. abscessus症などで専門的に用いられる場合がある。

# 投与量・1日1回と単回投与
- 日本のアミカシン硫酸塩注射液の一般的な成人添付文書用法：1回100～200mgを1日2回点滴静注。製品・投与経路ごとの添付文書を確認する。
- JIHSのAMR対策補遺では、条件を満たす膀胱炎に15mg/kgの単回点滴静注、その他の感染症に初回20mg/kg後TDMで調整する投与例が示される。これらは国内添付文書の通常用法と異なるため、施設方針・適応・責任体制を確認する。
- 1日1回投与の考え方は高いピークを確保し、PAEを活用すること。腎機能低下では投与間隔が24時間を超える場合もある。
- 実投与量は、腎機能、透析・CRRT、肥満時の投与量算出体重、感染部位、MIC、重症度、TDM結果を踏まえて設計する。
- このノート内のmg/kgは参考的な初期投与例であり、個別患者への投与指示ではない。

# 腎機能・透析と投与設計
- AMKは主として腎排泄。腎機能低下やAKIではクリアランスが低下し、投与間隔の延長・TDMが必要になりやすい。
- 腎機能が変動するICU患者では、推算CrClだけでなく尿量・経時的な血清Crの変化を確認する。
- 肥満時は実体重を無条件にmg/kgへ代入しない。補正体重等の採用と施設プロトコルを確認する。
- 透析・CRRT、ARC（腎クリアランス亢進）では標準用量をそのまま適用せず、実測濃度に基づき個別設計する。

# PK/PD・TDM
- 目標とする薬効指標の一例はピーク／MIC比8～10。MIC、測定時刻、投与法によって解釈する。
- ピークは有効性の評価、トラフは蓄積・毒性リスクの評価に役立つ。採血時刻は投与終了との関係を必ず記録する。
- 日本の抗菌薬TDM臨床実践ガイドライン2022では、AMKの1日1回投与の目標トラフ値を4 μg/mL未満としている。
- JIHSのAMR対策補遺はIDSAに基づくトラフ5 μg/mL未満も記載する。両者の差を把握し、投与方法・施設基準・治療目的に合わせて判断する。
- 単回投与と連日投与、一般細菌感染と抗酸菌症、注射用AMKと吸入ALISでは濃度目標や監視法を一律に扱わない。

# 副作用・安全性
- 重要な有害事象は腎障害（AKI）、第8脳神経障害（難聴・耳鳴り・めまい・平衡障害）、神経筋遮断作用。
- 高齢、腎機能低下、長期使用、他の腎毒性・耳毒性薬との併用でリスクが高まる。
- AMK開始前から腎機能・尿量を確認し、治療中も検査値と聴覚・前庭症状を観察する。
- ALIS吸入製剤では咳、嗄声、呼吸器症状なども確認する。全身性副作用の可能性がゼロになるわけではない。

# 治療症例とAST提案
- 症例A：ESBL産生E. coliの単純性膀胱炎、経口選択肢が乏しくAMK感性。単回静注の適否を検討し、腎盂腎炎・菌血症・尿路閉塞がないことを確認する。
- 症例B：ESBL産生菌による腎盂腎炎、AMK感性。AMKを選ぶ場合は単回で治療完結と考えず、臨床経過・腎機能・TDM・代替薬を検討する。
- 症例C：敗血症で緑膿菌疑い。経験的なAMK併用の必要性を検討し、菌種・感受性判明後は中止可能か確認する。
- 症例D：多剤併用療法が奏効しない肺MAC症。ALISの適応、既治療歴、培養、吸入手技、呼吸器・聴覚有害事象を確認する。
- ASTチェック：①感染部位 ②原因菌/MIC ③代替薬 ④単回・1日1回・併用・吸入の目的 ⑤腎機能/体重 ⑥TDM採血時刻と結果 ⑦終了/変更計画。

# 安全上の注意
- 国内承認用法とガイドラインの高用量・単回投与例を同一視しない。
- 静注用アミカシンと吸入ALISを代替可能な同一製剤として扱わない。
- AMK感性という結果だけで感染部位を問わず単剤投与を推奨しない。
- 患者情報や院内限定情報は公開リポジトリに登録しない。
